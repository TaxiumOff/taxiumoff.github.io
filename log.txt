DIRECTION VISUELLE
- Entre deux : esprit éditeur de code de l’ancienne version + structure éditoriale actuelle.
- Pro mais stylé : fond encre, papier clair, titre serif, accents ambre, bordures 1 px, ombres sobres.
- Aucun dégradé, orbe, glassmorphism, pastille animée ni badge générique.
- Fenêtre de code dans le hero : chrome d’éditeur, points de couleur, coloration, barre d’état. Pas de post-it, pas de numéros de ligne.

CONVENTIONS
- Sections : projets majeurs (vitrine, non filtrés) puis projets personnels (filtres Catégorie + Langage).
- Catégories : jeux-video / cybersecurite. Langages : python / cpp.
- Contact au vouvoiement. Aucun projet inventé.
- Ne pas supprimer :
    <!-- BEGIN BIG PROJECTS --> ... <!-- END BIG PROJECTS -->
    <!-- BEGIN SMALL PROJECTS --> ... <!-- END SMALL PROJECTS -->

LIENS ET CODE
- Un dépôt GitHub public donne trois liens : le dépôt, une archive ZIP et l’exécutable (fichier du dépôt).
- Aucun fichier source n’est hébergé sur le site.
- Le panneau local liste les fichiers texte du dépôt via l’API GitHub ; le fichier choisi est affiché sur la fiche sous forme d’aperçu en lecture seule.
- Les blocs de code des fiches sont stylés en lecteur de code, sans numéros de ligne.

ENCADRÉS
