4. CATÉGORIES ET FILTRES
- Catégories : jeux-video ("Jeux vidéo") et cybersecurite ("Cybersécurité").
- Langages : python ("Python") et cpp ("C++").
- Deux lignes de filtres dans CHAQUE section projets, avec "Tous" aux deux niveaux.
- Boutons : data-category-filter / data-language-filter, état aria-pressed.
- Les filtres des deux sections sont synchronisés par valeur (on compare dataset[key], pas l'identité du bouton).
- Règle d'affichage : une carte est visible seulement si la catégorie ET le langage correspondent, ou si le filtre est "all".
- Messages d'attente automatiques : #projects-empty et #projects-big-empty.

5. CONVENTIONS DES CARTES
- Petite carte : <article class="project-card project-card--small reveal" data-category="..." data-language="...">
- Grosse carte : project-card--big + <span class="project-card__cover">Nom du projet</span> dans la vignette.
- Styles de vignette : thumb--one (violet, jeux vidéo), thumb--two (vert, cybersécurité), thumb--three (orange, choix libre).
- Badges : .project-card__badge = catégorie ; .project-card__lang avec .lang-python ou .lang-cpp = langage.
- NE PAS SUPPRIMER CES MARQUEURS :
    <!-- BEGIN SMALL PROJECTS --> ... <!-- END SMALL PROJECTS -->
    <!-- BEGIN BIG PROJECTS --> ... <!-- END BIG PROJECTS -->
- Les cartes sont insérées juste avant le marqueur END correspondant.

6. AJOUTER UN PROJET
- Commande : python add_project.py (depuis le dossier du dépôt).
- Questions posées : type (1 = petit, 2 = gros), nom, date de création, catégorie (1/2), langage (1/2), description courte, technologies séparées par des virgules, lien de démonstration, lien du code source, style de vignette (1/2/3).
- Le script échappe le HTML (html.escape) et écrit directement dans index.html. Recharger la page ensuite.
- Testé sur une copie temporaire pour un petit et un gros projet : OK. Aucun projet réel n'a encore été ajouté.
